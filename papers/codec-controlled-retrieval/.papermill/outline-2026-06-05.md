# Outline (2026-06-05), target PoPETs 2027

Narrative arc (the spine the reader should feel):
"Retrieval structures are unanimous that non-member output is arbitrary junk.
It is not. It is uniform on a linear subspace you can design with a public codec,
and whether your design takes hold is a sharp rank threshold. The payoff is a
static data structure that hides value-frequency for free, where encrypted
databases pay per query." Theory builds to the threshold (the surprise), then the
security section cashes it out, then evaluation makes it concrete, then we are
honest about the boundary (and the opposite-pulling second attack).

Estimated length: 12 to 14 pages (PoPETs format), excluding references and appendix.

## 1. Introduction (1.5 pp)
- Purpose: motivate, state the gap, list contributions, sketch the threat model.
- Key content:
  - Outsourced/encrypted key-value lookup leaks value frequency; deterministic
    encryption is the cautionary baseline (NKW). Online defenses (PANCAKE, FSE) hide
    frequency at per-query or re-encoding cost.
  - The overlooked surface: a RETRIEVAL structure (Bloomier/ribbon/XOR) returns a
    value for EVERY key, member or not, with no membership gate. The literature
    calls the non-member return "arbitrary". Nobody characterizes it.
  - Contribution bullets (tiered honestly): (B) the codec-control law survives the
    move to GF(2)-linear retrieval; (C, headline) a sharp GF(2)-span threshold
    governs when it holds; (security) structural, zero-per-query frequency-hiding,
    formalized as FreqDist with idealized advantage zero; (eval) implemented,
    validated to 10M keys; (reconciliation) an honest account of the opposite-pulling
    multi-instance attack.
  - One line placing this as the linear-retrieval companion to cipher-maps.
- Key argument: the "arbitrary" non-member output is a designable, thresholded,
  security-relevant object.

## 2. Background and the linear-retrieval view (1.5 pp)
- Purpose: give the reader the GF(2) lens and the notation, so the theorems land.
- Key content:
  - Codecs: prefix/dense codecs, classes, codespace share alpha(v) = |class(v)|/2^M.
  - Ribbon/XOR retrieval as solving a banded GF(2) system; lookup(y) = a_y^T z is a
    GF(2)-linear form (dense ~64-bit band, NOT a 3-wise XOR; state this, it matters).
  - The stored-codeword span W = span{c(x)}; the idealized model M1 (uniform action
    on W) flagged up front as an idealization whose gap is measured later (T5).
  - Space context (near-r|S| bits) so the reader knows this rides on a practical
    structure.
- Key argument: a retrieval query is a linear functional of stored state, so its
  reachable outputs live in a subspace. That single fact drives everything.

## 3. The non-member output distribution (2.5 pp)
- Purpose: the core characterization and the frequency-independence lemma.
- Subsections:
  - 3.1 Output lives on the stored span (T1, T2): R(z) = W; under M1,
    P(out=v) = |class(v) cap W| / |W|. Proof via row space + the builder facts
    (free slots zero, pivots are XORs of stored codewords).
  - 3.2 Frequency independence (T3): W is the span of the SET of stored codewords,
    so the law is invariant to multiplicities. This is the security lemma; signpost
    it forward.
- Key argument: the non-member law is a function of W and the public codec only.

## 4. The sharp codec-control threshold (2.5 pp) [HEADLINE]
- Purpose: the surprise and the central theorem.
- Key content:
  - Setup: balanced linear codec, classes as cosets of the homophone subspace C,
    the quotient Q, the projection pi.
  - Subspace-meets-coset lemma -> per-class mass is 0 or 1/K' (two-valued).
  - Theorem (T4): full codec control (P(out=v)=alpha(v) for all v) iff pi(W)=Q iff
    rank pi|_W = log2 K. Sharpness: no graded regime; below threshold whole classes
    get exactly zero. The gf2_rank(stored) bridge gives the engineering rule.
  - Remark: the skewed/variable-length codec case is open (honest deferral).
- Key argument: control is all-or-stratified, a step in an integer rank, not a dial.

## 5. From the idealized model to the real construction (1.5 pp)
- Purpose: close the M1 gap honestly so the security claim is grounded.
- Key content (T5): delta = TV(real law, M1 law) is small, scale-independent
  (measured flat to 10M), and governed by storage REDUNDANCY (how far above
  threshold W sits), not N. The measured delta straddles the query sampling-noise
  floor, so the systematic deviation is at or below resolution for rich support.
  Labeled honestly as a characterization, not a closed-form bound.
- Key argument: the real structure realizes the idealization to measurement
  precision when support is rich; the residual is a known, small, frequency-free
  quantity that the security bound absorbs.

## 6. Security: frequency-analysis resistance (2 pp)
- Purpose: cash out the theory as a security property.
- Key content:
  - Threat model: oracle access, non-member queries, goal = recover storage
    frequency. Place against NKW / PANCAKE / FSE.
  - The FreqDist distinguishing game.
  - Idealized: Adv = 0 (from T3 + T1), for ANY adversary, ANY query count.
  - Real: Adv <= 2(delta(p0)+delta(p1)) via the triangle inequality through M1;
    plug in the T5 numbers (~0.012 rich, ~0.04 thin); E2 confirms it does not grow
    with the frequency gap.
  - Independence, not comparative (why this framing is immune to direction errors).
  - Scope and boundary (value-frequency channel only; not access/volume; static).
- Key argument: storage frequency never enters the observable, so frequency
  analysis is structurally defeated, at zero per-query cost.

## 7. Two attacks pull opposite ways (0.75 pp)
- Purpose: intellectual honesty and a genuine finding.
- Key content: single-instance frequency analysis is defeated by FLAT codecs
  (independence), the multi-instance coincidence oracle by CONCENTRATED (Huffman)
  codecs (acc(t) = 1 - (1/2) sum alpha^t, minimized by concentration). No single
  optimal codec; this is the linear-retrieval instance of the cipher-maps
  (TV, length) frontier. (Note: this corrects an earlier inverted reading; the
  cipher-maps companion now agrees.)
- Key argument: the optimal codec is attack-model-dependent; we state both poles.

## 8. Evaluation (2 pp)
- Purpose: make the theory concrete and reproducible.
- Key content (E1-E4, tables with CIs from source/results/):

    CIs degenerate, so the transition is deterministic in rank, not just sharp).
  - E2: FreqDist indistinguishability + the redundancy effect (with the noise-floor

  - E3: scale-independence to 10M and the sampling-floor comparison (0.00334).
  - E4: the corrected coincidence-oracle direction (concentration helps), MC vs

  - Implementation note: header-only C++23 (maph), reproducible scripts.
- Key argument: every theorem has a passing empirical check at scale.
